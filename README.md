# 🎮 Maze Runner

A real-time maze puzzle game with unique solutions. Pure client-side JavaScript - no server required.

## 📁 Folder Architecture

```
maze_generator/
├── index.html          # Complete game (HTML + CSS + JS)
├── CNAME              # GitHub Pages domain config
└── README.md          # This file
```

## 🎯 How to Play

1. Open `index.html` in any modern browser
2. Use **Arrow Keys** or **WASD** to navigate (desktop)
3. Use **Swipe** or **On-screen D-pad** (mobile)
4. Navigate from the green start to the pink exit 🚩
5. Click "Show Hint" if you get stuck

**Features:**
- 4 difficulty levels (Easy to Extreme)
- Real-time timer and move counter
- Unique solution for every maze
- Mobile-friendly responsive design
